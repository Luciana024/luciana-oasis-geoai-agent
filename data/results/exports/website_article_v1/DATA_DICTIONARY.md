# 结果说明（给合作者）

位置：`data/results/exports/website_article_v1/`

English version: `DATA_DICTIONARY.en.md`

这份说明面向**没有跑过模型的合作者**。先读「一、名词」，再查文件和列名。

一句话：我们在爱丁堡 111 个小区上，用过去 7 天的滚动七日感染率，预报 **7 天后** 的滚动七日感染率，并给出不确定性和（仅最后一天的）解释。

---

## 一、名词（请先读）

### 地理

| 说法 | 是什么 |
|---|---|
| **IZ** | Intermediate Zone，苏格兰的小区单元。爱丁堡用 **2011 年版**，一共 **111** 个。 |
| **iz_code** | 小区代码，如 `S02001576`。地图、预报、解释都靠它对齐。 |
| **node_index** | 这 111 个小区在模型里的编号，0 到 110。不要改顺序。 |

### 我们预报的数

| 说法 | 是什么 |
|---|---|
| **滚动七日感染率** | 公共卫生发布的「最近 7 天阳性率」，单位：**每 10 万人**。不是「当天新增多少人」。 |
| **issue_date（发布/截止日）** | 模型当时能看到的最后一天。相当于「今天」。 |
| **target_report_date（目标日）** | 要预报的那一天。永远是截止日再加 **7 天**。 |
| **观测值 observed_rate** | 目标日后来真正公布的率。有这个数，才能算准不准。 |
| **预报值 predicted_rate** | 模型给出的目标日率。 |

例子：截止日 2023-02-18，目标日就是 2023-02-25。  
模型用 2 月 12–18 日的率，去预报 2 月 25 日的滚动七日率。

### U01、U10 是什么

测试期大约 9 个月。我们**不是**只训一次模型用到底，而是大约每 **28 天换一套新权重**。一共换了 10 次，编号：

**U01, U02, …, U10**  = 第 1 次更新、第 2 次更新、…、第 10 次（最后一次）更新。

可以把它理解成「第几版模型」。

| 编号 | 大约负责哪些截止日 | 白话 |
|---|---|---|
| U01 | 2022-05-31 到 2022-06-27 | 测试期第一版 |
| U02 | 2022-06-28 到 2022-07-25 | 第二版 |
| … | … | … |
| **U10** | 有标签回测到 2023-02-18；3 月 4 日那次外推也用这一版 | **最后一版** |

看某一天的图，必须用**那一天对应的 U0x**，不要把 10 版平均后再解释那天。

**checkpoint** = 这一版模型存下来的权重文件。表里的 `checkpoint_id` 和 `update_id` 在本项目里是同一个东西（U01–U10）。

### 两种日期，不要混

| 类型 | 是什么 | 有没有「标准答案」 | 能不能算准不准 |
|---|---|---|---|
| **回测（retrospective）** | 2022-06-07 到 2023-02-25，共 **264** 个目标日 | 有，已经公布 | 能。这是论文里的精度 |
| **未核实外推** | 只有 **2023-03-04** | **没有**。数据只到 2 月 25 日 | **不能**算 MAE、R²、覆盖率 |

3 月 4 日用的是 **U10**（最后一版），因为 2 月 25 日仍落在 U10 预定的 28 天使用期内。

### 模型怎么预报（直观）

1. 先看「今天」的率 \(Y_t\)。  
2. 模型只预报 **变化量** \(\Delta\)（7 天后比今天高多少或低多少）。  
3. 预报率 = 今天的率 + 变化量。  
4. **持续性基线（persistence）**：假装 7 天后还是今天的率。用来比较「模型有没有比原地踏步更好」。

### α（alpha）是什么

模型同时看三张关系网：

- **地理 α_geo**：小区是否相邻  
- **交通 α_transport**：路网/公交方向  
- **流动 α_mobility**：通勤 OD（不是实时人流）

三个数 **大于 0，加起来等于 1**。例如 U10 大约是 0.32 / 0.32 / 0.36。

**正确说法：**「这一版模型相对更依赖流动图一些。」  
**错误说法：**「流动解释了 36% 的病例 / 36% 的接种需求。」

α **不是** 风险地图，也 **不是** 分配权重。

### 不确定性

| 说法 | 是什么 |
|---|---|
| **predicted_sigma（σ）** | 模型觉得这次预报有多「没把握」。越大越不确定。网站用连续颜色画。 |
| **80% / 95% 区间** | 「我们认为真实值大概落在这条带子里」。校准后的区间比原始高斯带子更可信。 |
| **uncertainty_flag** | 若 σ 高于**这一版模型**历史上 90% 的 σ，标 `high`，否则 `normal`。辅助，不是必须图层。 |

不确定性在 **264 个回测日每天都有**，3 月 4 日也有。  
3 月 4 日没有观测，所以只能画「模型有多不确定」，不能检查区间有没有套住真值。

### GeoShapley 是什么

用来回答：「**这个小区的预报**，相对全市中等水平，主要被哪些社会经济变量往上/往下推？」

- 不是因果（不能说「因为贫穷所以发病」）  
- 不解释神经网络内部的 embedding 维  
- 和 α 是两回事  
- **目前只算了 3 月 4 日、U10 这一天**。回测 264 天没有解释（当时为省计算关掉了）

### 精度指标（论文表用）

| 指标 | 白话 | 好不好 |
|---|---|---|
| **MAE** | 平均每次差多少（每 10 万人） | 越小越好。滚动模型 **46.53**，持续性 **50.66** |
| **MAE skill** | 比持续性好多少。`1 − 模型MAE/持续性MAE` | 正数 = 比原地踏步好。滚动 **+0.081**（大约好 8%） |
| **RMSE** | 也是误差，大错罚得更重 | 越小越好 |
| **R²** | 能解释目标日变化的比例（相对用平均值瞎猜） | 越接近 1 越好。滚动 **0.67** |
| **bias（偏差）** | 预报平均偏高还是偏低 | 0 最好。正 = 系统性报高了 |
| **覆盖率** | 真实值落在预报区间里的比例 | 名义 80% 的区间，实际大约盖住 82%；名义 95% 大约 95% |

这些数字**只来自回测**，不含 3 月 4 日。

## 三、每个文件：干什么、怎么来的、列名是什么

### 1) `website/retrospective_predictions.csv`（回测预报，主表）

**一行：** 某一个目标日、某一个小区。  
**多少行：** 264 天 × 111 小区 = 29,304。  
**怎么来的：** 用当天对应的那一版模型（U01–U10）预报；有公布值，所以能算误差。  
**用来：** 网页上选日期后画：预报图、真值图、误差图、不确定性图；比较模型和「假设不变」。

| 列名 | 合作者可读的意思 |
|---|---|
| `issue_date` | 截止日（模型能看到的最后一天） |
| `target_report_date` | 被预报的那一天（截止日 + 7） |
| `update_id` | 用的哪一版模型，U01–U10 |
| `checkpoint_id` | 同上 |
| `iz_code` | 小区代码 |
| `node_index` | 小区编号 0–110 |
| `observed_rate` | 当天真实滚动七日率 |
| `anchor_rate_y_t` | 截止日当天的真实率（预报的起点） |
| `predicted_delta` | 模型认为 7 天后会升/降多少 |
| `predicted_rate` | 预报率 = 起点 + 变化量 |
| `predicted_sigma` | 没把握程度（越大越不确定） |
| `calibrated80_lower` / `upper` | 校准后约 80% 区间的下/上界 |
| `calibrated95_lower` / `upper` | 校准后约 95% 区间的下/上界 |
| `uncertainty_flag` | `high` = 这一版里相对很不确定；否则 `normal` |
| `persistence_prediction` | 「假设 7 天后还是今天」的值，等于起点 |
| `model_error` | 预报 − 真值（正 = 报高了） |
| `model_absolute_error` | 误差的绝对值（总是 ≥ 0） |
| `persistence_absolute_error` | 「假设不变」的绝对误差 |
| `alpha_geo` | 这一版里地理图的权重 |
| `alpha_transport` | 这一版里交通图的权重 |
| `alpha_mobility` | 这一版里流动图的权重 |
| `node_order_hash` | 111 个小区顺序的指纹，用来防对错位 |
| `forecast_status` | 固定为 `retrospective_evaluation`（有真值的回测） |
| `observed_target_available` | 固定为 true（有公布值） |

### 2) `website/future_forecast_20230304.csv`（3 月 4 日，未核实）

**一行：** 2023-03-04 的一个小区（111 行）。  
**怎么来的：** 数据只到 2 月 25 日。用 **U10**，看 2 月 19–25 日，预报 3 月 4 日。没有再训练。  
**用来：** 网页上单独一天；若讨论「下一周布接种点」，风险用这里的预报率和 σ。  
**没有：** 真值、误差。不要算准不准。

比回测表多出来的列：

| 列名 | 意思 |
|---|---|
| `predicted_variance` | σ 的平方 |
| `include_in_metrics` | 固定 false：不要进精度表 |
| `forecast_status` | `unverified_extrapolation`（未核实外推） |
| `observed_rate` 和所有误差列 | 空的，因为没有 3 月 4 日公布值 |

### 3) `website/geoshapley.csv`（解释，只有一天）

**一行：** 3 月 4 日、一个小区、一个解释分量。  
**怎么来的：** 只动这一个小区的社会经济变量和位置，看预报怎么变，再分解成各部分贡献。  
**用来：** 点选小区看「谁把预报往上/往下推」。  
**没有：** 其他 264 个回测日。

| 列名 | 意思 |
|---|---|
| `component` | 哪一类：`baseline` 全市中等水平起步；`main` 某变量本身；`location` 位置；`location_interaction` 位置和变量的组合 |
| `feature_name` | 具体是哪个变量，见下表 |
| `shapley_value` | 这部分让预报率加了多少（可为负） |
| `predicted_rate` | 该小区的预报率 |
| `reconstructed_prediction` | 把各部分加回来，应几乎等于预报率 |
| `additivity_error` | 加回来差了多少（本次几乎为 0） |
| `explanation_scope` | `target_iz_local`：只解释这一个小区 |
| `alpha_*` | 当天 U10 的图权重（背景信息，不是解释值） |

`feature_name` 对照：

| 表里的名字 | 通俗意思 |
|---|---|
| `baseline` | 如果这个小区各项都处在全市中等，预报会是多少 |
| `income_deprivation` | 收入剥夺 |
| `employment_deprivation` | 就业剥夺 |
| `higher_education` | 高等教育 |
| `overcrowding` | 住房过度拥挤 |
| `crime` | 邻里犯罪 |
| `public_transport_time_to_gp` | 坐公交去诊所要多久 |
| `location` | 地理位置（东/北坐标一起） |
| `location_x_收入_deprivation` 等 | 「位置 × 某变量」的额外组合，不是主效应的重复 |

各部分加起来应等于该小区预报率。这是相关分解，不是「因为贫困所以发病」。不要直接拿去当布点分数。

### 4) `website/rolling_alpha.csv`（十版模型的图权重）

**一行：** 一个 U0x。  
**用来：** 网页上画「十次更新里三张图的权重怎么变」。

| 列名 | 意思 |
|---|---|
| `update_id` | U01–U10 |
| `update_date` | 这一版开始用的日期 |
| `forecast_start` / `forecast_end` | 这一版在回测里负责的截止日范围 |
| `alpha_geo` / `alpha_transport` / `alpha_mobility` | 三张图的权重，和为 1 |
| `selected_epoch` | 训练时选中的第几轮（内部记录） |
| `training_window_days` | 每次用过去 730 天拟合 |
| `checkpoint_checksum` | 权重文件指纹，防拿错文件 |

### 5) `website/date_selector.csv`

网页日期菜单。只有回测那 264 个截止日。  
**不要**把训练期、验证期加进去，也 **不要** 把 3 月 4 日混进同一个普通菜单（应单独标「未核实」）。

### 6) `website/edinburgh_iz_boundaries.geojson`

111 个小区边界，网页坐标 **经纬度（EPSG:4326）**。用 `iz_code` 和预报表拼接。

### 7) `website/model_metadata.json`

给网页页脚用的模型说明：预报定义、图的含义、校准方法、解释的限制。

## 四、论文表（article/）

`article/` 里的数字已四舍五入，方便贴进 Word。同样内容的精确小数在 `article/full_precision/`。

### table01 数据怎么切

我们把时间从早到晚切成：训练 → 验证（一半用来选模型轮次，一半用来校准不确定性）→ 测试。

| 列名 | 意思 |
|---|---|
| `split_name` | 哪一段 |
| `fraction` | 占全部目标日的比例 |
| `target_start_date` / `target_end_date` | 这段的起止目标日 |
| `n_unique_target_dates` | 有多少个不同的目标日 |
| `n_valid_iz_date_cells` | 小区×日 的格子数（大约 111 × 天数） |
| `mean_infection_rate` | 这段里感染率的平均 |
| `std_infection_rate` | 感染率有多散 |
| `mean_target_delta` | 平均来说 7 天后比今天升还是降 |
| `std_target_delta` | 变化量有多散 |

测试段：2022-06-07 到 2023-02-25。这段才是网页日期和精度表用的。

### table02 三种方法谁更准（全体测试）

三行：持续性（假设不变）、固定模型（只训一次）、滚动模型（U01–U10，主结果）。

列名见上面的 MAE、skill、RMSE、R²、bias。  
滚动模型：MAE 46.53，比持续性好约 8%。

### table03 分疫情阶段

测试期再切：

- **下降/波动期** 2022-06-07 到 2022-09-19  
- **晚期稳定期** 从 **2022-09-20** 到 2023-02-25  
- **全体**

晚期 skill 是负的：那时候「假设不变」往往更稳。论文不要写成全程都赢。

### table04 不确定性评得准不准

只评回测。  
`raw_*` = 按正态公式直接画的带子（对照）。  
`calibrated_*` = 用验证期校准过的带子（正式报告用这个）。

| 列名 | 意思 |
|---|---|
| `nominal_coverage` | 我们声称的 80% 或 95% |
| `observed_coverage` | 实际上真值落进带子的比例（0 到 1） |
| `mean/median_interval_width` | 带子有多宽 |
| `mean_predicted_sigma` | 平均没把握程度 |
| `corr_sigma_absolute_error` | σ 大的时候，误差是不是也大（约 0.63，大体同向） |
| `gaussian_nll` | 概率预报的一种综合打分，越小越好 |

### table05a / 05b 图权重

- **05a：** 每一版 U01–U10 自己的三个 α。讲某一天必须看 05a。  
- **05b：** 十版的平均和波动。只能写「总体混合、流动略高」，**不能**用来解释某一天。

### table06 3 月 4 日解释摘要

每个社会经济变量一行（外加 location）。

| 列名 | 意思 |
|---|---|
| `mean_absolute_main_effect` | 这个变量对预报的拉动平均有多强（不管正负） |
| `mean_signed_main_effect` | 平均是往上推还是往下压 |
| `mean_absolute_location_interaction` | 和位置组合后额外拉动有多强；location 那一行是空的 |
| `positive_effect_iz_fraction` | 111 个小区里，有多大比例是往上推 |
| `negative_effect_iz_fraction` | 有多大比例是往下压 |

例如收入剥夺：大约一半小区往上、一半往下，所以不要写成「全市都因收入剥夺而升高」。

## 五、网页上建议怎么给合作者看

1. 选日期（回测 264 天；3 月 4 日单独标「尚未有公布值」）。  
2. 地图：预报率；回测日可再切到真值、误差；**每天都可以**切到不确定性 σ。  
3. 点小区：预报、（若有）真值、区间、这一版是 U0几、三个 α。  
4. 仅 3 月 4 日：再开解释（选一个变量看地图，或看该小区各部分加减）。  
5. 另附一张小图：U01 到 U10 的 α 变化。  
6. 精度表、划分表放在「方法」里，不要挡在地图前面。

接种点还没做。若做，风险用预报率和 σ；解释只给人看，不要自动当选址分数。还缺候选点和出行时间。
