# Data redistribution review required

The curated repository contains only the boundary and derived/frozen artefacts
needed for inference and result inspection. Before making this repository
public, the project authors must verify redistribution terms for every included
boundary and derived dataset and document the applicable attribution.

The separate full-training archive additionally contains PHS, SIMD,
healthcare, commuting and Geofabrik/OSM source files. Do not upload that archive
to GitHub or share it publicly until redistribution rights have been confirmed.

The project uses the evaluation-only, all-rights-reserved terms in `LICENSE`.
`THIRD_PARTY_NOTICES` separately records third-party software attribution.
